# 研究结论全记录

> 按时间线保留各阶段实验的完整结论。所有回测区间与数据包日期均显式标注（比较必须统一区间）。

## 环境与数据

- 计算：Modal serverless（Starter 计划：并发容器 100 / GPU 并发 10），入口 `modal_qlib_cn_a10g.py`
- 数据：chenditc/investment_data 每日 release（A股日频，qlib 格式，全量包 565MB、历史 append-only
  已实证零修订）。**每日信号（--best --daily）为单容器自包含模式：每次运行自动下载最新包，
  不依赖 Volume**；Volume `qlib-cn-data` 仅供研究批并行（多容器共享一份数据）使用
- 股票池：csi500 全历史成分（~1800 只，按区间过滤），benchmark SH000905
- 费率基准：买 0.05% + 卖 0.15%（敏感区间见文末）

## 实验矩阵（关键结论汇总）

| 实验 | 结论 |
|---|---|
| 标签周期 | **20 日收益是最优标签**（2 日 IC≈0.03-0.04 噪声过大；20 日 IC 0.108；40 日 IC 峰值 0.137 但收益证伪 -6.8%——IC 峰值≠收益峰值） |
| 模型 | **LGB 显著优于 GRU/ALSTM**（RNN 在 2 日标签下训练不充分，集成中拖累 LGB；官方+本地双重证据） |
| 特征 | **Alpha158 优于 Alpha360**（vcheck 2×2 矩阵：两数据包下 158 均稳定 +9.4%，360 波动且跨容器方差大） |
| 组合构造 | **top50 等权最优**（top20/30/70 均更差；分数加权无信息——头部分数差异太小） |
| 调仓方式 | **每日微调 n_drop=3 最优**（n_drop=1/2 显著差；20 日硬调仓三次实证远差于微调） |
| 超参搜索 | 官方默认已近最优（40 组随机搜索无提升），且 **Rank IC ≠ 赚钱**（Alpha158 IC 高 4 倍收益反低的历史实证） |
| 基本面因子 | 6 因子（ROE/毛利率/增速/PE/PB）无提升甚至下降——季度信息与短标签周期错配 |
| 多周期融合 | 20+60 日融合 -4.7%——弱成员稀释强信号；40 日标签证伪 |

## 各阶段结果详录

### P0：信号可靠性检验（2026-09-17）

| 检验 | 结果 |
|---|---|
| 分组单调性 | **Spearman 0.907 单调**，且只有头部组（top10%）正收益——区分力集中在买入部位 |
| IC 衰减 | 1日 0.042 / 10日 0.086 / 20日 0.108 / **40日 0.137** / 60日 0.096 |
| n_drop 网格（360 上） | 1: -3.2% / 2: +0.4% / **3: +6.35%** / 5: -2.1% |
| 分月归因 | 6/9 个月负超额，前 2 月占正超额 91%——**信号极不稳定** |

### vcheck：版本敏感性验证（2026-09-17）——两个旧判断被推翻

1. **数据版本敏感性证伪**：两数据包历史零差异，chenditc 是 append-only。"版本敏感性"实为**回测区间末端效应**（3 个交易日即可让年化数字摆动数个点——单段年化数字不可轻信，比较必须统一区间）
2. **特征终判**：Alpha158 双包一致 +9.4%（IR 0.497，跨容器可复现 9.43/9.42），Alpha360 较弱且跨容器差 1.4 个点（360 维特征下 LGB 多线程非确定性疑似放大）。**Alpha158 > Alpha360 终判成立**
3. n_drop 在 158 上重测：3 依然最优（+9.42%）

### P2-13：滚动 Walk-Forward 终局验证（2026-09-17，21 个月严格无前视）

| 2025Q1 | Q2 | Q3 | Q4 | 2026Q1 | Q2 | Q3 |
|---|---|---|---|---|---|---|
| +7.3% | +0.4% | **-9.5%** | -1.5% | +1.8% | **-19.6%** | **+22.0%** |

- **真实期望：年化有成本超额 +0.47%**（正超额月份 11/21，最差连续 3 月为负）
- **+9.4% 是 2026Q3 单季 +22% 撑起的窗口运气**——单段年化数字不可作为预期
- 季度分布 -19.6% ~ +22.0%：期望/波动比极差；风格切换期（2026Q2）完全失效
- **信号为真但转化后期望趋零**——纯量价技术面在 A 股的天花板已被实证

### P1-9：成本敏感性（事后推算，2026-09-17，零重跑）

原理：QLib 回测中成本 ≈ 每日换手 × 费率的线性累积（不改变选股路径），可从已有 report 事后推算。

| 费率情景 | 单边成本 | 年化期望 | 判定 |
|---|---|---|---|
| 券商万一免五+印花税 | ~0.04% | **+2.20%** | 弱正——小仓位卫星有条件成立 |
| 降一半 | ~0.05% | +1.91% | 弱正 |
| 回测基准 | ~0.10% | +0.47% | 边际 |
| 双倍悲观（滑点大） | ~0.20% | **-2.42%** | 不应交易 |

**核心洞察：弱信号的生死完全取决于实际交易成本**——毛超额仅 2-3%，费率从 0.04% 到 0.2% 就把期望从 +2.2% 打到 -2.4%。**决策权在你的实际成交条件**。正月比例（11/21）在各费率下不变——月度不稳定是信号本质。

## 批次 A/B/C：参数体系收尾（2026-09-17，多重检验纪律下执行）

> 统一粗筛区间 2026-01-01~09-11；终审为批次 C 滚动（2021Q1~2026Q3 共 23 个季度窗口，expanding 训练严格无前视）。
> 纪律：单窗口差异 <3pp 视为噪声；LGB 超参最优（trial11 +28.6% vs 默认 26.2%，差 2.4pp）**不采纳**；记录全部结果而非幸存者。
> 原始数据：`results/batch_a/`、`results/batch_b/`、`results/batch_c/`

### 批次 A（粗筛）

- **topk×n_drop 耦合解谜**：top20/nd3 = +11.9%（nd1/nd2 为 +8.4%，nd3 并非换手错位假象——在 top20 下依然最优）
- **股票池**：csi300 +2.5% / csi500 +8.4% / **csi1000 +26.2%**（IR 1.23，maxDD -18.1%）

### 批次 B（csi1000 上，参数依据）

- **训练起点**：2011 与 2013 结果完全一致 → **csi1000 指数 2014 年发布，成分数据 2014 年前为空**，起点实验在该池失效（2016 为唯一有效值）
- **expanding > sliding**（+26.2% vs +22.6%）
- **LGB 超参 12 组**：8.1%~28.6%，最优与默认差 2.4pp——噪声级，不采纳

### 批次 C（5.5 年滚动终审，唯一裁判）——⚠️ 前视 bug 修复后数字大改

**Bug 发现（2026-09-18 审计）**：批次 C 初版的窗口生成把 `train_end` 误写为 `valid_end`，
导致 train 末样本的 20 日标签直接泄露 **test 头部** 20 天的真实收益（真前视）；
同时 valid 与 train 区间重叠（early stopping 失真）。P2 滚动的窗口设计是正确的
（train_end = valid_start − 1 季度），两管道曾通过同季对照（0.9pp）——该对照只验证了
"csi500+top20 的 2025Q1 单窗口"，未覆盖 csi1000 与全分布，故未及早发现。

**修复（train_end 改为 T-2 季度末，与 P2 对齐）前后对比（23 窗口，2021Q1~2026Q3）：**

| 配置 | 修复前（虚高） | **修复后（可信）** | 正窗口 | 最差季 | 最差年 |
|---|---|---|---|---|---|
| csi1000 + top20/nd2 | +15.3% | **+7.5%** | 13/23 | -20.0% | 2025 年 -9.2% |
| csi500 + top20/nd3 | +9.4% | **+0.6%** | 13/23 | -23.0% | 2024 年 -3.5% |

**关键交叉验证**：修复后 csi500 的 +0.6% 与 P2 滚动（独立实现的正确管道）的 +0.47% 收敛——
两个正确管道相互印证，前视 bug 的虚高贡献被精确定量（csi500 +8.8pp / csi1000 +7.7pp）。

修复后 csi1000 逐年：2021 +20% / 2022 +19% / 2023 +12% / 2024 +0% / **2025 -9%** / 2026YTD +1%。

### 关键解读（诚实审视，按修复后数字）

1. **csi1000 池的优势是真实的（+7.5% vs csi500 +0.6%），但幅度只有初版的一半**——初版 +15% 中约 7.7pp 是前视 bug 的虚高：2021-2023/2025-26 的超额高峰与 A 股小盘牛市完全同步，2024 年 -15.9% 正是 size 风格反转的惩罚。窗口序列与真实市场叙事吻合（2021-23 微盘牛、2024 初微盘崩盘），不是随机噪声。
2. **对未来的合理预期**：若 size 风格延续 → 年化 +15% 量级可期；若再度反转 → 复现 2024 型 -16% 年份。**不能用 23 窗口均值直接当预期**——它隐含了"小盘行情延续"假设。
3. **可执行性硬约束**：csi1000 top20 是 20 只中盘偏小股票，回测按 1 亿资金无冲击假设不现实；个人小资金（10-50 万）可能可行，更大资金需流动性过滤（P1-8 在此场景重新变得必要）。
4. **遗留审计项**：chenditc 的 csi1000 历史成分（2021 窗口用的是当时成分还是现在成分回填？）未验证——若为当前成分回填历史，则存在幸存者偏差，+15% 高估。**实盘前必须审计**。
5. 与 P2 结论的关系：P2 的 +0.5% 对应"csi500+top50 在 2025-26"；批次 C 表明**池子/topk/区间的改变会大幅改变滚动估计**——信号的期望不是单一数字，是"配置×市场风格"的函数。

### 幸存者偏差审计（2026-09-18，已关闭）

csi1000.txt 实测：2803 只股票平均 11.8 条成分区间记录、逐年进出分布正常、无"当前成分回填"特征
（若回填则每股仅一条 [2014,2026] 记录）——**chenditc 用的是真实历史成分，幸存者偏差排除**。

### 修复后复核（2026-09-18 四层独立验证，最终置信）

| 层 | 验证内容 | 结果 |
|---|---|---|
| 1 | 算术一致性：46 个窗口的 excess_total ≈ daily_mean×n_days、年化重算 | ✅ 全部通过（偏差 <0.5pp） |
| 2 | 双管道对照：修复后批次C vs P2 同池 7 个重叠季度 | ✅ 方向一致 6/7、**相关系数 0.941** |
| 3 | 机制解释：前视污染（train末20天标签=test头20天）+ valid重叠，两 bug 同除后模型全变 | ✅ 与 2025 翻负（微盘两波崩盘的外部事实）自洽 |
| 4 | 外部量级：+7.5% vs 中证1000 指增行业（平均 5-10%，2022 年行业上沿 20%+） | ✅ 落在"行业平均偏上"，非离谱值 |

**附带发现（重要实践洞察）**：2026 年滚动训练模型累计 +1.1%，而批次 A 静态训练（截止 2024-12）同信号 +26.2%
——**包含近期数据的滚动训练比静态训练差 ~25pp**（模型追风格后失效）。实盘必然只能滚动训练（无前视），
故批次 C 的滚动数字就是实盘可预期水平；批次 A/B 的单窗口数字不可作为实盘预期。

### 终审（2026-09-18，RD-Agent/消息面前的最后计算）

| 检验 | 结果 |
|---|---|
| **统计置信区间**（此前缺失） | 季度超额 std=9.6%，23 窗口下 t=0.94、**p=0.18（不显著）**，年化 95%CI = [-8.2%, +23.2%]；剔除 2021 后年化 +4.8% |
| **完全独立实现的端到端复算**（手写全部配置/超额计算，不经过任何本管道公共代码） | csi1000 w09 窗口：独立实现 -1.78% vs 管道 -1.63%，**偏差 0.15pp** ✅ 两条独立代码路径收敛 |

**终审结论（必须按此口径使用）**：
1. **计算正确性**：程序逻辑经算术一致性、双管道对照、独立端到端复算三重交叉验证，结果可信
2. **但统计强度不足**：+7.5% 是 5.5 年的实现均值，**不是统计上确立的期望**——数据无法排除真实期望为零甚至为负（p=0.18）
3. **实操含义**：仓位按"信号可能无效"来定（卫星仓 ≤10-20%）；**paper trading 的样本外积累（每月真实数据）比任何回测延长都更值钱**——它是唯一不依赖历史假设的证据
4. 提升 p 值的现实路径：csi1000 历史只有 2014 起，无法延长；只能靠前向样本积累

**残余不确定性（代码审计无法消除，方向标注）**：
1. 小盘股真实冲击成本高于回测假设（方向：实盘收益低于 +7.5%）
2. 回测 1 亿资金无冲击——个人小资金下此假设影响小
3. size beta 的未来持续性（风格风险，非计算问题）
4. valid 末样本 20 日标签 peek test 头几天（QLib 官方配置同样存在，量级极小，行业通行）
5. 年化用简单求和口径（比复利保守）
