# 40 — 新对话唯一入口：CSI1000 选股系统 MVP 开发交接（2026-10-10）

## 使命与优先级

**新对话主目标：尽快交付一个稳定、可追溯、可持续更新的 CSI1000 选股系统（研究 / paper，不是自动实盘交易）。** 每日 T 收盘形成信号，T+1 开盘计划执行；Top20 排名、模型版本、数据日期、风险状态必须明确；不把尚未认证的回测数字作为产品保证。不再为了历史收益精确值无限追加独立审计 PR。

**本交接文件是目标和未决状态的快照，不是实际 Modal 审计 PASS 结果。** 需先看 [39 号收尾实验及证据提交规范](39-stage-b-audit-closeout-modal-runbook-20261010.md) 与实际审核后的 `*.json`/日志（如有）。没有实验结果就填 `BLOCKED/NOT_RUN`；不要凭 CI 绿灯改写结论。

## 本轮审计的退出与风险边界

1. 报价订阅使用历史可能曾持有股票的静态联合，股票信号与可买集合仍按当日 CSI1000 PIT，不得重现原 F1“退指后失价无法卖出”错误。
2. `SZ000488` 2025-02-20 有正式停牌公告；新的独立账本仅对这个明确日期处理“保留前次估值”，其余未知缺价继续 BLOCKED。
3. `SZ000488` 2025-02-21 的 ST 5% 限幅及可能受限卖出**没有市场成交认证**。如果第 39 号实验通过，只能标识 `PASS_RESEARCH_ACCOUNTING_ONLY`；无论审计是否结束，历史执行可行性仍可能为 BLOCKED。
4. 不购买/构建完整历史 ST 库、不回测所有候选/参数、不在已消耗尾段反复优化、不为强行 PASS 而补编行情。
5. 如果新发现问题会直接造成**当前每日信号未来信息泄露、用错股票池、模型/数据日期不匹配、失效模型被宣传为已验证、或 paper 状态破坏**，必须阻止受影响的启用/展示并优先修复；否则记入研究待办并保持 MVP 进度。

## 新对话的第一项任务（建议交付一个 MVP PR）

**先审查现有系统，而不是重写：**

1. 确认最新 GitHub `main`、生产部署与 Actions 的实际版本，以及最新两日数据/信号是否正常、唯一、可追溯。仓库代码存在不代表容器正在运行。
2. 明确 `signal_data_date`、`model_fit_asof`、`train_end`、`candidate_id`、`data_provider_fingerprint`、`lineage` 的输出合同和失败状态；发现关键缺失就 fail-closed 或显著标明“状态未证实”，不造假。
3. 检查 paper 当日成交限制/停牌与当前 ST 风险如何显示。**最小可用**的处理是冻结名单/日期的状态提示及无法确认时的明确标识；如果要硬排除 ST，则必须说明过滤时点与对 Top20 构成的影响，不能隐式改变研究策略。
4. 完成一个隔离端到端 smoke：最新完整交易日行情 -> 最新信号 -> Top20 artifact -> paper 计划 -> 网站读数，保留数据日期、版本、artifact hash；不覆盖历史已发布数据。**若需访问用户 Modal 部署，由授权账户手动执行并提供日志。**
5. 确保网页不会将 Stage-B 模拟收益曲线拼接到 2026-10-12 才开始的前向 paper 曲线，不会把旧 winner 或 baseline 错写为“最优已认证”。
6. 在前向层保留并列候选的不可回填预测，以供今后决定需不需要重新调参；不要为了初版交付等待其统计优势已显著。

## 交付/完成定义

- 每日发布的 Top20 可以查到**正确模型版本、数据日、发布日和信号哈希**；无新数据、交易日不符、数据错误时有清楚可见的非正常状态。
- 生产/研究 lineage 和真实推广授权清楚分离；paper 只说明模拟成交假设，不能承诺实盘可成交。
- 既有站点可展示最新榜单与真实前向记录；相关 CI、样例产物、失败路径和 Modal 运行证据可复核。
- **模型选择和调参仍属下一阶段研究决策。** MVP 可以在模型“研究暂定”状态下运行，不自动进行股票真实交易。
