## 经验教训（写给未来的自己）

1. **单段年化数字不可信**：区间末端 3 天可摆动 6 个点——比较必须统一区间，结论必须附窗口
2. **IC ≠ 赚钱**（两次实证）：全截面排序与头部收益是两回事
3. **官方最优 ≠ 我们的最优**：官方超参是 2 日标签时代的产物；但重造轮子前先确认官方已覆盖
4. **先验证信号真伪，再优化执行**：P2-13 若早做，P1 的部分实验可省
5. **弱信号的生死在成本**：毛超额 2-3% 时，费率假设比模型选择更重要
6. **不要把"测过的配置的天花板"外推为"信息源的天花板"**：我们实测 Alpha158/360 + LGB 期望 ≈ +0.5%，
   但这只证明这两个固定因子库弱，不证明量价信息量本身挖尽了——RD-Agent(Q) 论文的样本外证据（CSI500
   2024-25 测试、LLM cutoff 隔离、IR 2.17 vs Alpha158 的 0.25）证明 LLM 假设驱动的因子组合能在
   同一信息源上大幅超越人工库。先查证再下"帮助有限"的结论（2026-09-17 自我修正）。

## RD-Agent 量价价值专述（2026-09-17 复核修正）

**原判断（已撤回）**："纯量价天花板不变，RD-Agent 是同一口井里更快地挖。"

**撤回依据**（RD-Agent(Q) 论文，NeurIPS 2025，arxiv 2505.15155，含样本外泛化实验）：

| 基准 | Alpha158 | Alpha360 | AutoAlpha（进化挖掘） | **R&D-Agent(Q)** |
|---|---|---|---|---|
| CSI300 2017-20 ARR | 5.70% | 4.38% | 4.00% | **14.21%**（o3-mini） |
| CSI500 2024-25 IR（样本外，LLM cutoff 隔离） | 0.25 | 0.25 | — | **2.17**（o4-mini） |
| NASDAQ100 2024-25 IR | 0.03 | 0.59 | 0.10 | **1.77** |
| 因子 IC（CSI300） | 0.034 | 0.042 | 0.033 | **0.053** |

关键点：样本外实验用 LLM 知识截止早于测试期的模型，数据泄漏被物理排除；测试期 2024-2025 近期数据，
两个市场结论一致。**同样的量价数据、同样的 Qlib 平台、同样的 LightGBM 底座，LLM 迭代挖出的 ~8 个因子
显著超越 158 个人工因子**。

**仍需保留的批判**：
1. **多空 vs 多头**：论文 IR 基于 daily long-short 排序策略；A 股个人无法做空，只能拿多头腿，
   收益预期需打折（打折幅度取决于因子对称性，未验证）
2. 微软自评 + 同行评审（NeurIPS 2025），独立复现报告暂缺；同赛道第三方方法（AutoAlpha 4%、
   Alpha-GPT）量级佐证了"LLM 假设生成"是关键增量而非"自动化"本身
3. 迭代评估仍为单区间——**我们的滚动验证框架应作为其产出的后置过滤器**（这是两个体系的结合点）

**修正后的定位**：RD-Agent 是当前量价层面证据等级最高的进攻方向，成本可控（论文口径 <$10/循环的
API 费 + Azure VM）。建议与 P3-14/15 并行评估：先在 Azure 部署跑 fin_factor（量价因子自迭代），
产出因子库后用本项目 P2 滚动框架复验（严格无前视 + 多头口径），通过者进入实盘候选池。
