# 实验文档导览

> Qlib A 股日频量化研究（2026-09）。本项目在 microsoft/qlib 之上构建了 Modal 云端研究管道，
> 完成了从信号验证到滚动终局评估的完整闭环。所有结论均基于实测数据，可复现。

## 一页纸速览（截至 2026-09-17）

- **固化配置**：LightGBM + Alpha158 + 20 日收益标签 + 2016-2024 滚动训练 + top50 等权 + n_drop=3
- **信号真实期望（21 个月滚动）**：年化有成本超额 **+0.47%**（实际期望取决于你的真实费率：万一约 +2.2%，双倍悲观 -2.4%）
- **信号特征**：真实但极薄——分组单调（Spearman 0.907）、月度极不稳定（11/21 正）、季度波动 ±20%
- **实盘定位**：不适合作为独立策略；仅适合 ≤10% 卫星仓 / 候选池参考 / 信号监控
- **下一步**：P3 信息维度（消息面因子、HIST 板块关系）
