# 实盘操作手册（含预期管理）

> **免责声明**：本手册仅为工程验证（paper trading）的操作记录规范，不构成投资建议。
> 文中任何信号、清单、数字不得作为投资决策依据；据此操作风险自负。

## 模型的能力边界

模型只提供**选股排序**：每个交易日对 csi1000 每只股票输出"未来 20 日收益"的相对预测分数（`--best --daily` 输出 top20 候选池；每 20 个交易日自动重训一次，其余日复用缓存模型）。

**它不提供**：总仓位建议、个股止损线、买卖时点、大盘择时——这些需要你自己的规则。

## 预期管理（终审版 2026-09-18，先读这个）

1. **配置与数字**：csi1000 + top20 + nd2（`--best --daily` 已固化，无需参数）。5.5 年滚动年化超额 **+11.6%（purge 后新口径，t=1.44 不显著）**——按"信号可能无效"定价；频率实验佐证（20 日重训 +12.7% / 60 日 +10.5%，1385 日序列，正日比例约 50%——收益靠盈亏比而非胜率）
2. **绝对收益 = 指数 β + 超额**：指数跌你照样亏（2022 中证1000 -21%，组合约 -2%；若风格反转年如 2025，超额本身 -9%）
3. **正常剧本**：单季最大回撤 -20%、连续失效年 -9%、正季度概率约 57%
4. **合理定位**：卫星仓 ≤10-20% 总资金；小盘流动性上限约 100-400 万组合规模；**先 3 个月 paper trading 再投真钱**
5. 实盘前先跑：`::verify_integrity`（口径审计）

## 月度操作流程

```
每月初（或每 20 个交易日）：
1. 跑每日信号（单容器自包含：自动下载最新数据，信号自动入库+推送）：
   modal run modal_qlib_cn_a10g.py --best --daily   # 无需 --force-data，每次必然最新
2. 大盘门控：中证1000 是否在 MA20 上方？
   - 是 → 按计划仓位执行（信号资金仅占你总资产的卫星仓 ≤10-20%）
   - 否 → 减到半仓或空仓（择时与选股分离）
   - size 风格门控：中证1000/沪深300 相对强弱转负时降半仓（2024 教训）
3. 建仓：等权买入榜单中不在当前持仓的股票（top20 每只约 5%）
   - **执行日保护（人工规则，发榜时无法预知 T+1 状态）**：
     · 跳过 T+1 高开 >5% 的股票（接近一字板排队无意义、成本恶化）
     · 跳过 T+1 停牌的股票（无法成交）
     · 已持仓股若 T+1 跌停开盘且想卖出——挂单排队，不市价砸；跌停日不计入止损判定
   - 说明：榜单自带的涨跌停过滤是**发榜日口径**（剔除 T 日已涨停的股，属保守提示：
     连板股 T+1 高开概率大且信号已被预支）；真正的 T+1 可成交性约束由上面的人工规则和
     回测引擎（limit_threshold=0.095）共同覆盖
4. 持有期间：
   - 单票跌破 -8%~-10% → 止损卖出（独立于模型的风险纪律，必须执行）
   - 可选：每 5 个交易日重跑榜单，分数跌出 top100 的提前换出
5. 到期：20 个交易日重新选池，循环
```

## 仓位与风控要点

- **总仓位**：弱信号不建议满仓；50-70% + 现金缓冲，或用大盘门控动态调节
- **个股仓位**：top50 等权最稳（分数差异小，加权无信息——已实证）
- **止损纪律**：单票 -8%~-10% 硬止损，防黑天鹅
- **先小仓位跟踪 1-2 个月**：把每日榜单+实际成交价+你的真实费率记录下来对账——这比任何回测都接近真相
- **跟踪记录**：记下起始日、榜单、买入价、实际费率；20 个交易日后对账实际超额 vs 信号预期
