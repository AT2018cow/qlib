# 实盘操作手册（含预期管理）

## 模型的能力边界

模型只提供**选股排序**：每个交易日对 csi500 每只股票输出"未来 20 日收益"的相对预测分数（`--best --daily` 输出 top50 候选池）。

**它不提供**：总仓位建议、个股止损线、买卖时点、大盘择时——这些需要你自己的规则。

## 预期管理（先读这个，再看流程）

1. **长期期望 ≈ 年化 +0.5% 有成本超额**（若你的费率是万一约 +2.2%；若滑点大可能是负的）——不是回测窗口展示的 +9.4%
2. **单季亏损 20% 是正常剧本**（2026Q2 实测 -19.6%），盈利靠个别季度爆发拉回
3. **合理定位**：≤10% 总资金的卫星仓 / 候选池参考（与你的判断结合）/ 信号监控。**不适合作为主要盈利来源**
4. 实盘前先跑：`modal run modal_qlib_cn_a10g.py::verify_integrity`（涨跌停口径审计）

## 月度操作流程

```
每月初（或每 20 个交易日）：
1. 跑每日信号：modal run modal_qlib_cn_a10g.py --best --daily --topk 50
2. 大盘门控：中证500 是否在 MA20 上方？
   - 是 → 按计划仓位执行（建议总仓位 50-70%，不强求满仓）
   - 否 → 减到半仓或空仓（择时与选股分离，用简单技术规则即可）
3. 建仓：等权买入榜单中不在当前持仓的股票（top50 每只约 1-1.5%）
4. 持有期间：
   - 单票跌破 -8%~-10% → 止损卖出（独立于模型的风险纪律，必须执行）
   - 可选：每 5 个交易日重跑榜单，分数跌出 top100 的提前换出
5. 到期：20 个交易日重新选池，循环
```

## 仓位与风控要点

- **总仓位**：弱信号不建议满仓；50-70% + 现金缓冲，或用大盘门控动态调节
- **个股仓位**：top50 等权最稳（分数差异小，加权无信息——已实证）
- **止损纪律**：单票 -8%~-10% 硬止损，防黑天鹅
- **先小仓位跟踪 1-2 个月**：把每日榜单+实际成交价+你的真实费率记录下来对账——这比任何回测都接近真相
- **跟踪记录**：记下起始日、榜单、买入价、实际费率；20 个交易日后对账实际超额 vs 信号预期
