## 1. 版本判定

按[发布版本策略](2026-10-19-quant-release-versioning-policy.md)，本轮建议 **`quant-v1.4.0`**，不建议 `2.0.0`：

- **无策略参数变化**：CSI300 `59b93929_top10_drop1_10d`、CSI500 `raw10d_c98856b4_top20_drop2_20d`、CSI1000 `c98856b4_top10_drop1` 未变；标签期限、TopK/DropN、成本口径、20-session 重训和 1M 本金未变。

如果仍要发 `2.0.0`，必须先单独定义“不兼容契约”的具体对象（archive/receipt schema、账户/journal、网站结果或执行时序），并补充迁移、兼容读取和回滚说明；不能仅因提交数量多而升 MAJOR。
