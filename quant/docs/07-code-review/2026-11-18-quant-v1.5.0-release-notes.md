# quant-v1.5.0

本版将三市场生产切换到收盘后发布。系统用 T 日收盘数据生成下一交易日的信号，并更新截至 T 日的网站模拟收益。原三市场模型配置、持仓规则、20 交易日重训周期及账户成本口径保持一致。

- 生产使用唯一自建 overlay archive。归档以内容摘要标识，消费者校验收据、日历与数据身份。配套整改覆盖 R01–R10、S01–S05 及后续复权边界。[Provider 整改与复审](https://github.com/AT2018cow/qlib/blob/d0fdb6d47f0060f85ff74a411dff4d36154f1cf9/quant/docs/07-code-review/2026-11-11-overlay-primary-review-remediation.md)
- 每个交易日 18:00 主跑、23:00 核验、23:15 按需自动恢复，下一交易日 07:00 做只读检查。主跑和恢复共用单一协调器。调度来源在日志中区分自然、定时恢复和人工覆盖。[收盘后生产整改](https://github.com/AT2018cow/qlib/blob/d0fdb6d47f0060f85ff74a411dff4d36154f1cf9/quant/docs/07-code-review/2026-11-11-postclose-independent-review-remediation.md)
- 网站复用经过校验的模拟增量祖先，并将公开榜单与账户计划关联到同一排名来源。三市场模拟账户分别核算。离线历史 ST 核验能力保留，日常网站计算采用参考模拟口径。
- 研究扩展层加强了缓存身份、净收益计算和候选发布证据校验。AR01–AR09 已通过本地复验，生产策略继续沿用既有配置。[研究整改报告](https://github.com/AT2018cow/qlib/blob/d0fdb6d47f0060f85ff74a411dff4d36154f1cf9/quant/docs/07-code-review/2026-11-12-research-backtest-strategy-selection-codex-remediation-report.md)
