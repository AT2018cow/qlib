## 3. Primary outcome, exact estimand, costs, and multiplicity

**Unit**: a paired, completed, eligible forward trading session. Fixed Top20/Drop2, Qlib-compatible close-ranking → next usable open as pending order, identical PIT candidate eligibility and held-quote union, independently accounted T+1 settlement; observed fills are **paper simulation**, not real fills. Both legs start on one common **first valid shadow settlement** with CNY 100,000,000 notional each, no Stage-B NAV carry-over, no assumed compounding from unobserved dates. All zero fill/unsettled risk carried in holdings/cash and labeled.

**Base costs**: BUY 5bp and SELL 15bp of filled adjusted open notional, CNY 5 minimum where implemented in frozen ledger contract. Log turn rates, pending/no-fill, corporate factor. Same costs both legs. Add a **separately labeled robustness stress** of +10bp per successfully simulated trade notional (freeze fills; not a market-impact simulation), and independently test +20bp. Neither stress turns saved fills into broker fills; lack of independent ST/orderbook execution certification remains a hard limitation.

**Primary paired series**: `delta_t = net_paper_return_baseline_t - net_paper_return_winner_t` on the same date, costs included, with no cherry-picked dates, no assuming daily independent returns. Scalar effect `238 * mean(delta_t)` in **simple annualized arithmetic percentage-points**, *not CAGR*. Show both legs' total return, CAGR, Sharpe (238 sessions, rf0), max drawdown, turnover, no-fill ratio, and active return to saved benchmark **only if labeled unverified**. Primary comparison cancels a common benchmark: does not require calling benchmark externally certified; externally certified relative-performance claims still require AR-05 separate gate.

**Inference pre-specified**: moving-block bootstrap of **paired** `delta_t`, fixed block length 5 consecutive trading sessions, 10,000 resamples, fixed RNG seed `20261011` (Python NumPy PCG64 version must be recorded); recompute `238*mean(delta)` each draw. One-sided lower percentile bound for `effect>0`: 99th confidence at **first and only 120-paired-session look** (alpha 0.01); if not passed, single final **240-paired-session look** using 96th one-sided bound (alpha 0.04). Union bound total one-sided familywise type-I alpha ≤ 0.05 for these two prespecified looks. A failed/insufficient first look **never** licenses new unregistered interim looks, alternate sample endpoints, seed sweeps, adding candidates, or changing costs. Record effect size + confidence bound even when not passing. If market data/coverage invalid, report `INSUFFICIENT_FORWARD_EVIDENCE`; do not relabel an extra peek as the first look.

**Comparability gate**: start and endpoint known before observing interim returns; minimum **120 valid paired completed trading sessions** for first analysis (and **240** for second), each over at least the same number of actual exchange trading sessions; at least **95%** of all exchange sessions since the first eligible shadow date must contain a pre-outcome matched immutable pair and complete settlement; any missed sessions remain missing and count against coverage. If coverage <95%, primary test stays `INVALID_COVERAGE` until a new separately approved protocol—never fill omissions. Safety-only ongoing P0 and no-fill monitoring is allowed without calculating/publishing strategy performance peeks.

## 4. Materiality / risk gates; cannot switch automatically

To **qualify for `PROPOSE_SWITCH`**, every condition below must hold on a predeclared look:

1. Frozen identity, PIT/labels/clock, point-in-time provider, no current P0, immutable-before-outcome matched pair and 95% coverage all verified by A+B reviewers. No major account mismatches (cash+holdings vs NAV, missed fills on suspended names, unexplained stale bars); pending positions and no-fills preserved.
2. One-sided block-bootstrap bound for `238*mean(delta_t)` **strictly above 0**, with at least **+3.0 percentage-points/year point-estimate** net paper return difference under base costs. First look alpha .01; second look .04; no off-schedule endpoint testing.
3. Under incremental +10bp stress, baseline-minus-winner *point estimate* is **still >0**; report +20bp as non-veto diagnostic and do not conceal failures. Any materially different ST/IPO/liquidity execution assumptions need a new reviewed robustness note, not stealth revised fill.
4. Baseline max drawdown is no more than **5 percentage-points deeper** than the contemporaneous winner's, and median session turnover not more than **1.25×** winner's (if denominator zero, gate fails pending explicit review); report both absolute levels, continuous exposure, pending/no-fill ratio, concentration, and sector/regime sensitivity. No data leakage, exception-driven NAV jumps, or unidentified corporate actions.
5. Independent research review demonstrates the results were not selected on 2025–2026 consumed-tail ranks, candidate/shadow selection was fixed here, historical ST/benchmark uncertainty is disclosed, and there is no existing current correctness P0. Any return comparison advertised as independently benchmark-adjusted must separately pass AR-05.
6. Written, separately approved **strategy-review PR** records source/date-range/artifact SHA256, statistical output and negative controls, failure modes, proposer/reviewer, activation version, rollback condition, and explicit `APPROVED_FOR_SWITCH` decision. `PROPOSE_SWITCH` **does not** modify `CANONICAL_PROFILE`, lineage, service, historical reports, or website by itself.

**Risk veto / stop**: discovered forward PIT/label/as-of leak or canonical identity drift → A line immediate fail-closed/recovery (P0), suspend inference until paired evidence valid; independent ledger mismatch or frequent unexplained paper no-fills → invalidate affected pairs, notify A line and/or scoped residual investigation; if >5% sessions invalid no qualification. Significant drawdown/liquidity incident prompts risk review but **cannot** trigger unregistered performance-driven switch. If baseline underperforms or CIs overlap zero, keep canonical and continue until one declared look is reached; no rescue parameter tuning.
