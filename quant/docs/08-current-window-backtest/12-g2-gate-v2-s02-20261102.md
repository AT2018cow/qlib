# 12 — CSI1000 G2 v2 门槛与 S02 候选（2026-11-02）

> **重要披露：v2 门槛是在看到 G2 结果之后确定的，因此它不是原始预注册门槛的“通过”，而是显式的风险偏好修订。** 该修订必须统一适用于后续市场，不能再针对单个候选反复调整。
>
> **账户口径：** 2026-11-03 起生产/研究统一 100 万；文中的 100M D8 失败是历史容量记录，1M 口径见第 3.1 节。

## 1. 为什么修改

G2 结果显示：

- S02/A 全周期 **CAGR 20.98%**、MaxDD **-39.76%**、Sharpe **0.863**，均优于 S01/A（17.01% / -50.32% / 0.693）；
- S02 的 2018 MaxDD 为 **-22.75%**，比 S01 的 -20.81% 深 **1.94pp**；
- S02 真实 +10bp 成本后 Sharpe **0.682**，比 S01 的 0.693 低 **0.011**；Calmar 0.339，略高于 S01 的 0.338；
- 2018 MDD 差异的 block bootstrap 置信区间很宽，1.94pp 在统计上不可区分；+10bp Sharpe 差异同样很小。

因此，操作员决定接受“小幅 2018 回撤让步 + 小幅成本后 Sharpe 让步”，但要求全周期回撤改善作为补偿。

## 2. v2 门槛（冻结）

### D2v2 — 2018 非劣 + 全周期补偿

- 2018 MaxDD 不得比 S01 深超过 **2pp**；
- 且全周期 MaxDD 必须比 S01 至少改善 **5pp**。

### D7v2 — 成本后门槛

- +10bp 后 Calmar ≥ S01 基线 Calmar；
- +10bp 后 Sharpe ≥ S01 基线 Sharpe - **0.02**；
- +20bp 后 CAGR > 0。

D1、D3、D4、D5 保持不变。
