# 20 — G2 1M 账户扩展到 2026-09-30（2025–2026 扩展观察）

> **性质：策略锁定后的扩展观察，不是选型依据。** 当前 profile、参数和执行规则均未因 2025–2026 结果调整；2026-10 起为线上真实 paper。

## 1. 为什么需要新信号

2018–2024 的 G2 冻结信号只到 `2024-12-31`。要延长到 `2026-09-30`，必须为当前三个 profile 生成 2025–2026 信号：

- CSI300：spine B（10d）
- CSI500：spine B（20d）
- CSI1000：spine A（20d）

不能直接从旧 2025–2026 研究取信号，因为那批信号对应旧 profile，不是当前生产 profile。

## 2. 相位连续性

G2 最后一个重训 asof 是 `2024-12-05`，其 20 日 block 因窗口结束被截断在 `2024-12-31`。扩展从同一 asof 继续：

- 第一个 fit：`2024-12-05`，预测到 `2025-01-02`；
- 之后每 20 个交易日重训，直到 `2026-09-30`；
- 每个市场 23 个 fit，三市场共 69 个 fit；
- 扩展 run：`regime_g2_ext_20261103_a1`（infi workspace Volume）。

扩展信号与 G2 在 `2024-12-05`–`2024-12-31` 的 19 个重叠交易日逐行一致；合并后为 `2018-01-02`–`2026-09-30`，共 2,123 个信号日。

## 3. 1M 回放结果

同一执行契约：T 收盘信号 → T+1 开盘、board-aware 涨跌停/停牌、5bp 买 / 15bp 卖、最低 5 元、100 股整手、100 万元账户。

### 3.3 一致性校验

用同一扩展信号重放 2018–2024 子段，三市场结果与现有 1M 表完全一致：

- CSI300：13.69% / -43.28% / 0.615
- CSI500：5.62% / -41.92% / 0.353
- CSI1000：17.72% / -50.08% / 0.714

说明扩展没有改变历史路径，只是追加了 2025–2026。

## 4. 解读边界

- 2025–2026 是策略锁定后的扩展观察，**不参与选型**；不能据此回头改参数或换 profile；
- 该段覆盖 2025 年上涨与 2026 年波动，短窗口收益不应外推；
- 2026-10 起为线上真实 paper，不属于本表；
- 成本压力仍为算术压力，不重新撮合。
