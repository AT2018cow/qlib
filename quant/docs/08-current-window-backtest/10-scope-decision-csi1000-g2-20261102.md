1. **股票池严格使用 CSI300 / CSI500 / CSI1000 指数自身成分股**；
2. **不添加双创、科创、行业、相关性等子池或选股约束**；
3. **S11（双创 40% 上限）暂缓**；

5. 当前保持 **买入等权**，不做个股仓位管理；
6. 三个市场各自 **100 万元独立账户**（2026-11-03 起；此前 100M 历史归档），不合并、不按市场等权；

## 2. 影响

## 3. CSI1000 G2 范围

只启动 CSI1000，暂不启动 CSI300/CSI500 G2。

### 3.1 训练

- 市场：CSI1000；
- Spine：A（现役 20d 标签）；
- 窗口：`2018-01-02 ～ 2024-12-31`；
- 20 个交易日滚动重训；
- 为覆盖 2018 的训练/验证历史，特征与拟合起点使用 `2012-01-01`；
- 与 G1 相同的 purge/valid 规则、生产 profile、LightGBM 超参；
- 目标：补齐 2018 熊市（D2）与 2018–2024 七年（D3–D8）；
- 预计 85 个切片，24 路并发，断点续跑。

### 3.2 回放

在 G2 信号上运行：

- S01：Top10/Drop1（基线）；
- S02：Top20/Drop2；
- S16：趋势/波动率门控；
- S18：账户级回撤熔断。

S16/S18 先做收益流复核，然后对通过 D1/D7 的版本做完整 Qlib 执行复核。

### 3.3 门槛

- D2：2018 熊市 MaxDD 不深于 S01，且超额 ≥ -2pp；
- D3：2018–2024 净 CAGR > 基准 +8pp，Calmar/Sharpe 均 > S01；
- D4：去掉最好一年后仍 > 基准 +4pp 且 Calmar > S01；
- D5：block bootstrap 月度超额 5% 分位 > 0；
- D6：相位/seed 一致性（后续）；
- D7：+10bp 后仍过 D3；+20bp 后 CAGR > 0；
- D8：容量/ADV 约束（后续）。

## 4. 边界

- 不因为 CSI1000 G2 通过就自动切换生产；
