# 09 — 三市场分别择优记分卡（100M 历史；2026-11-03 起统一 1M）

> 账户口径更新：本文历史结果仍为 100M 可复现记录；自 2026-11-03 起生产/研究统一 100 万，详见 `13-production-1m-cutover-20261102.md`。

> **性质：R3（2021-02-19～2024-02-05）研究筛选。** 三个市场各自独立账户、独立比较、独立选冠军/备选；不做三市场等权、不合并净值。2025-01～2026-09 holdout 未打开。

## 0. 账户口径

- 每个市场独立账户，初始资金 **1 亿元**；
- 三个账户互不输血、不合并、不按市场等权；
- 每个市场只和自己的 S01/A 基线比较；
- S17 三市场组合不纳入本轮选择，仅保留为对照。

## 3. 分层规则

- **Tier 1**：D1 + D3 + D7(+10bp) + D7(+20bp) 全部通过；
- **Tier 2**：D1 + D3 + D7(+10bp) 通过，但 +20bp 未过；
- **Tier 3**：D1 通过，但 D3/成本门槛未过；
- **Tier 4**：D1 未过。

当前结果：

- CSI1000：Tier 1（S16、S18）；
- CSI300 / CSI500：Tier 2，不能称为“通过 G1/G2”，只能进入下一轮复核。

## 4. 关键结论

1. **三个市场必须分开选**：CSI1000 的最优是 S16/S18，CSI500 是 S18，CSI300 只有回撤保护，不存在统一冠军。
2. **CSI300 和 CSI500 的 +20bp 仍为负**，说明成本/换手是硬约束；不能因为 R3 回撤改善就直接上线。
3. **CSI1000 的 S16/S18 是当前最接近可上线的候选**，但仍是 R3 样本内结果，必须过 G2 的 2018 和 D2–D8。
4. **S17 等权不再作为主方案**；如果未来要合并报表，只做展示层汇总，不做资金等权。
5. **账户规模历史为 1 亿；2026-11-03 起统一 100 万**；100M 结果保留为可复现历史，新研究按 1M 口径。

## 5. 下一步（G2，按市场独立）

1. 对每个市场的冠军/备选做完整 Qlib 执行复核（S16/S18 不能只用收益流近似）。
2. 补 2018 熊市（D2）与 2018–2024 七年 D3–D8。
3. 对 CSI300/CSI500 继续寻找能过 +20bp 的低换手变体；优先 S09 buffer/排名滞后，而不是周频。
4. 每个市场独立通过后再打开 holdout；不因为另一个市场表现好而降低本市场门槛。
5. 生产仍保持三账户独立，不合并、不等权。
