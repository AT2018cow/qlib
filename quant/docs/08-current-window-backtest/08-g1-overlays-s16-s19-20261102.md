# 08 — G1 后的 S16/S17/S18/S19 overlay 结果

> **性质：R3（2021-02-18～2024-02-05）研究筛选，不是生产切换批准。** 2025-01～2026-09 holdout 未使用。S16/S18 是收益流 overlay 近似，不是完整 Qlib 重新撮合；G2 需要真实执行复核。

## 0. 结论摘要

1. **S16 趋势/波动率门控对 CSI1000 最强**：基于 A/S01，CAGR **+10.76%**、MaxDD **-18.94%**、Sharpe **0.603**；+10bp 后 CAGR +6.44%，+20bp 后 **+1.74%**，是少数通过 +20bp 的方向。
2. **S18 回撤熔断把 CSI1000 的 MaxDD 压到 -18.58%**，CAGR +7.98%，+20bp 后 **+4.01%**；但 CSI300 的 S18 平均仓位只有 **10.9%**，出现明显“现金陷阱”，不能直接采用。
3. **CSI500 的 S18 在 S01 基础上把 CAGR 从 -6.82% 提到 +2.08%、MaxDD 从 -37.73% 压到 -18.40%**；+10bp 仍为正（+0.07%），但 +20bp 为 -2.02%，D7 未过。
4. **S17 三市场组合**：最优格子等权 CAGR -3.17%、MaxDD -32.07%，优于现役三市场等权（-12.96%/-44.24%）；但 +20bp 后 -17.62%，成本仍是硬约束。
5. **周频/月频调仓明确不优**：换手从约 20%/日降到 4%/1%，但 CSI300/CSI500 的 CAGR 和 MaxDD 同时恶化；只有 CSI1000 周频 MaxDD 略好（-35.84% vs -37.70%），但 CAGR 从 +2.60% 降到 -1.46%。
6. **当前仍不应切生产**。R3 是压力/研究窗口，且 S16/S18 的 overlay 成本与现金收益是近似；需要 G2 的真实执行复核和 holdout。

使用 R3 最优格子（CSI300 B/S01、CSI500 B/S02、CSI1000 A/S01）或现役 A/S01；20 日再平衡；组合层换手按 10bp 计。

## 6. 风险与限制

1. **Overlay 是收益流近似**：S16/S18 用日收益乘以目标仓位，并按 5bp 买 / 15bp 卖对仓位变化计成本；没有重新撮合成分股，也没有现金收益。
2. **S16 阈值是预注册的**，但 R3 仍被用于选择基础格子，因此不是干净 OOS。
3. **S18 的恢复规则使用账户 NAV MA20**；CSI300 的低平均仓位说明它可能长期停留在现金。G2 需要与“benchmark MA20 恢复”版本对照，不能只挑 R3 最好看的版本。
4. **S17 使用 R3 最优格子**，存在选择偏差；现役版本（current）才是无选择偏差的对照。
5. **holdout 仍封存**；2026-10 仅作压力报告，不参与选择。

## 7. 下一步（G2）

1. 对 **CSI1000 S16/S18** 做完整 Qlib 执行复核：真实减仓/加仓、现金、board-aware 成交、成本。
2. 对 **CSI500 S18** 做同样复核；CSI300 S16 作为回撤保护对照。
3. 补 **2018 熊市**（D2）和 2018–2024 七年 D3–D8；用 block bootstrap 检查稳健性。
4. 研究 **S09 buffer/排名滞后**，替代固定周频，以降低换手而不牺牲退出速度。
5. 通过 G2 后再打开 2025-01～2026-09 holdout；最后才讨论 shadow/生产切换。
