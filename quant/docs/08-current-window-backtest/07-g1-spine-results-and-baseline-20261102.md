# 07 — G1 脊柱结果与 S01/S02 连续账户基线

> **性质：研究压力测试与候选筛选，不是生产切换批准。** 2025-01～2026-09 仍为封存 holdout；本报告只使用 2021-02-18～2024-02-05 的 R3 压力窗口。
>
> **账户口径更新：** 本文历史回放为 100M；1M 方案暂缓，将随新策略一起切换，详见 `13-production-1m-cutover-20261102.md`。历史结果保留为可复现记录。

## 0. 结论摘要

1. **G1 完成：222/222 个切片 PASS，6 条 spine 全部装配，724 个交易日全覆盖，无重复、无 NaN。**
2. **周期互换（Spine B）在 CSI300 / CSI500 上显著改善**：CSI300 B/S01 的 CAGR 从 -18.48% 改善到 -10.60%，MaxDD 从 -47.85% 收窄到 -37.72%；CSI500 B/S01 的 CAGR 从 -23.21% 改善到 -6.82%，MaxDD 从 -56.52% 收窄到 -37.73%。
3. **CSI500 B/S02 是 R3 风险调整后最好的格子**：CAGR -3.64%、MaxDD -30.28%、相对基准超额 CAGR +10.09pp；但 +10bp 成本后 CAGR 降至 -10.14%，**D7 成本门槛未通过**。
4. **CSI1000 维持 A/S01 最优**：CAGR +2.60%、MaxDD -37.70%、Sharpe 0.228；B/S02 的 CAGR 2.51%、MaxDD -39.03%、Sharpe 0.222，几乎持平但没有超过。
5. **当前没有任何候选可以直接通过 D7（+20bp 后 CAGR > 0）**。R3 的约束不是收益方向，而是 **20%/日左右的换手与成本**；这使“降低换手/风险 overlay”比“硬换模型”更优先。

## 2. 回放口径

- 信号：G1 frozen `signal.parquet`；T 日收盘分数，T+1 开盘执行。

**结论：**

- **D1 有多个候选通过**，尤其 CSI500 B/S01、B/S02；CSI300 B/S01 依赖替代条件。
- **D7 没有任何候选通过**。成本压力下，20%/日换手使 +20bp 后的 CAGR 全部为负。
- D2（2018 熊市）、D3 七年全周期、D4/D5/D6/D8 尚未执行；因此不能宣称任何候选“通过 G1”。
- 由于 D7 是硬门槛，当前最优先的研究方向不是继续换模型，而是 **降低换手/成本** 与 **风险 overlay**。

## 5. 关键发现

1. **周期标签互换不是普适改进。** 对 CSI300/CSI500（现役 20d/10d 各自）换成互补周期，R3 明显改善；对 CSI1000（现役 20d）换成 10d 反而略差。
2. **CSI500 的现役 A/S01 在 R3 表现最差**（CAGR -23.21%、MaxDD -56.52%），而 B/S02 改善最大；但它是最依赖成本假设的格子。
3. **CSI1000 的现役 A/S01 是唯一 R3 正 CAGR 的基线**，且 MaxDD 浅于基准；不应为了统一周期而牺牲它。
4. **换手是共同瓶颈。** 所有格子日均换手约 20%，+10bp 成本大致吃掉 6–8pp CAGR；周/月调仓或 buffer 规则可能比换模型更高 ROI，但必须同时检查回撤是否变大。
5. **连续账户与旧 block-chained 结果存在量级差异。** 旧报告的 CSI300/CSI500/CSI1000 S01 MaxDD 为 -56.00%/-65.71%/-44.27%；连续账户为 -47.85%/-56.52%/-37.70%。方向一致，但绝对值不能混用；本报告以连续账户为准。
